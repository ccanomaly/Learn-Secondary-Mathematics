Exponent Laws

Exponents follows laws that are important and useful to utilize, especially when simplifying expressions. The laws they follow are what we call exponent rules, here they are below.

Letting $a$, $b$, $n$, and $m$ be real numbers,
Product rule: $a^m * a^n = a^{m+n}$
Quotient Rule: $\frac{a^m}{a^n} = a^{m-n}$
Power of a power rule: $(a^m)^n= a^{mn}$
Power of a product rule: $(a*b)^m = a^m*b^m$
Power of a quotient rule: $(\frac{a}{b})^m = \frac{a^m}{b^m}$
Negative exponent rule: $a^{-m} = \frac{1}{a^m}$
Zero exponent rule: $a^{0} = 1$
Fractional exponent rule: $a^{\frac{m}{n}} = \sqrt[n]{a^m}$

* Although it is not an explicit exponent rule, it is important to note that $a^1 = a$, that is any number to the power of one is just the number itself.

Square root as an exponent

One important fact that we gain from exponent laws is that taking the square root of a number is the same as taking the number to the power of $\frac{1}{2}$. This can be shown by using the fractioanl exponent rule.

$a^{\frac{1}{2}}=\sqrt{2}{a^1}=\sqrt{a}$

How these rules are used

Exponent rules, as said before, are used to simplify exponential expressions. It is best to learn these rules by applying them in examples!

Examples

Evaluate $2 * 2^2$ using exponent rules. Show Solution

Utilizing the the product rule for exponents $2*2^2 = 2^{1+2}= 2^3 = 8$ (remember 2^1 = 2).

Evaluate $\frac{3^3}{3^2}$ using exponent rules. Show Solution

Utilizing the the quotient rule for exponents $\frac{3^3}{3^2}= 3^{3-2} = 3^1=3$.

Evaluate $5^0$ using exponent rules. Show Solution

Utilizing the the zero exponent rule for exponents $5^0=1$.

Evaluate $(2^2)^3$ using exponent rules. Show Solution

Utilizing the the power of a power rule for exponents $(2^2)^2=2^{2*3}=2^6=64$.

Evaluate $(\frac{4}{5})^2$ using exponent rules. Show Solution

Utilizing the the power of a quotient rule for exponents $(\frac{4}{5})^2=\frac{16}{25}$.

Evaluate $(4*3)^3$ using exponent rules. Show Solution

Utilizing the the power of a product rule for exponents $(4*3)^3=4^3*3^3=64*27=1728$.

Evaluate $9^{-2}$ using exponent rules. Show Solution

Utilizing the the negative exponent rule, $9^{-2}=\frac{1}{9^2}=\frac{1}{81}$.

Evaluate $8^{\frac{2}{3}}$ using exponent rules. Show Solution

Utilizing the the fractional exponent rule, $8^{\frac{2}{3}} =\sqrt[3]{8^2}=\sqrt[3]{64}=4$.
